# ЗВЁЗДЫ — тёмный сайт с премиум OSINT за 50⭐

Тёмный сайт со звёздным небом. Владелец — **@davny**. Есть бесплатный раздел с открытыми OSINT-инструментами и закрытый премиум-раздел за **50 звёзд**.

## Файлы

```
index.html   — главная с бесплатным и премиум-разделами
style.css    — тёмная неоновая тема
stars.js     — анимированное звёздное небо
codes.js     — список действующих кодов премиум-доступа
main.js      — логика премиум-доступа (проверка кода)
admin.html   — админка для владельца (выдача кодов)
README.md
```

## Как работает платный доступ

- Кнопка «Оплатить 50★» ведёт на Telegram `@davny`, где ты принимаешь оплату звёздами.
- После оплаты выдаёшь покупателю код из списка `codes.js`.
- Ввод кода на сайте открывает премиум-раздел и запоминает доступ в браузере.

## Админка (admin.html)

- Открой `admin.html` и войди по паролю (по умолчанию `admin123`).
- Добавляй/удаляй коды премиума.
- Скачай обновлённый `codes.js` и заново залей его в репозиторий на GitHub — после этого новые коды заработают у покупателей.

**Смени пароль:** в `admin.html` найди `var ADMIN_PASS = "admin123";` и замени на свой.

## Честное ограничение

Сайт на GitHub Pages — статический. Все файлы, включая `codes.js` и пароль в `admin.html`, лежат открыто в репозитории, поэтому это **схема выдачи кодов, а не настоящая защита** (её можно обойти). Для реального контроля доступа и банов нужен сервер и база данных. Выдача кодов — рабочий сценарий, которого ты просил.

## Публикация на GitHub Pages

1. Создай репозиторий (например `stars`).
2. Залей `index.html`, `style.css`, `stars.js`, `main.js`.
3. `Repo → Settings → Pages` → Branch `main` → `/ (root)` → Save.
4. Сайт на `https://<твой-логин>.github.io/stars/`.

Если репозиторий назвать `<твой-логин>.github.io` — Pages включится автоматически.
