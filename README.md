# ✦ давний осинт — премиум OSINT за 50⭐

Тёмный сайт со звёздным небом. Владелец — **@davny**. Есть бесплатный раздел с базовыми OSINT-инструментами и закрытый премиум-раздел «давний осинт» за **50 звёзд**.

## Разделы

- Главная: имя, статистика, бесплатные инструменты, премиум, «как это работает», FAQ.
- **Админка** (`admin.html`) — управление кодами премиум-доступа по паролю.

## Файлы

```
index.html   — главная страница сайта
style.css    — тёмная неоновая тема
stars.js     — анимированное звёздное небо
codes.js     — список действующих кодов премиума
main.js      — логика открытия премиума по коду
admin.html   — админка владельца (выдача кодов)
README.md
```

## Как работает платный доступ

- Кнопка «Оплатить 50★» ведёт на Telegram `@davny`, где проходит оплата звёздами.
- После оплаты владелец выдаёт код из списка `codes.js`.
- Ввод кода на сайте открывает премиум-раздел и запоминает доступ в браузере.

## Честное ограничение

Сайт на GitHub Pages — статический. Все файлы (включая коды и пароль) лежат открыто в репозитории, поэтому это **схема выдачи кодов, а не настоящая защита**. Для реального контроля доступа и банов нужен сервер и база данных.
